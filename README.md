
# Finance Platform

Painel de controle financeiro pessoal desenvolvido com Next.js, React, TypeScript e Tailwind CSS.

## Sobre o projeto

Aplicação web para organizar receitas e despesas, acompanhar o saldo financeiro e visualizar a distribuição dos gastos por categoria.

## Funcionalidades

- Cadastro de receitas e despesas
- Edição e exclusão de transações
- Classificação por categorias
- Filtro de transações por categoria
- Seleção de mês e ano
- Resumo de receitas, despesas e saldo
- Gráfico de distribuição de despesas
- Armazenamento local com localStorage

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts
- Lucide React

## Como executar

Clone o repositório:

```bash
git clone https://github.com/mkleeo/finance-platform.git
```

Entre na pasta e instale as dependências:

```bash
cd finance-platform
npm install
```

Inicie o servidor:

```bash
npm run dev
```

Acesse http://localhost:3000.
